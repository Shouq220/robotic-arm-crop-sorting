# Robotic Arm Crop Sorting System

An intelligent sorting system that uses a 6-DOF robotic arm to automatically sort fruits by color, simulating industrial agricultural automation.

## Features
- Detects fruit color using a TCS34725 color sensor
- Controls a 6-DOF robotic arm to pick and place each fruit in its matching bin
- Fully automatic sorting without manual input

## Hardware
- Arduino Mega
- 6-DOF robotic arm
- TCS34725 color sensor

## Built With
- C++
- Arduino IDE
